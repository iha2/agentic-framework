## Quick commands

```bash
graphify update .                              # build/refresh graph
graphify query "<question>"                    # scoped subgraph (primary)
graphify path "<A>" "<B>"                      # dependency path
graphify explain "<concept>"                   # node + neighbors
```

Cursor rule: query graphify before Grep/Read exploration. See canonical guide for hooks, reports, troubleshooting, and token benchmarks.
